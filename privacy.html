Privacy policy

Last updated October 31, 2026

Aina is a personal assistant run privately by one person for their own use. The only Google account it connects to is its owner's. This page describes what it does with data from that account.

What Aina accesses

  • Gmail: reading messages so it can answer questions about them and tell its owner about mail that matters; changing labels; and sending mail only when its owner asks it to. It can also save drafts. The Gmail permission it asks for (gmail.modify) would let it archive messages or move them to the trash; it does not delete anything permanently.
  • Google Calendar: reading the list of calendars, and reading, adding, moving and cancelling events.

Where the data goes

Data is processed and stored on computers its owner controls. It is not sold or rented, and it is not used for advertising. It leaves those computers only in the ways below.

  • A model provider. To answer a request, the relevant text, which can include the text of an email or a calendar event, is sent to the model provider its owner has chosen: the Anthropic API (Claude), or, if its owner selects it, OpenAI, Google Gemini, or another OpenAI-compatible service. Text goes to a provider only when it is the one chosen. Each provider processes the text to produce the answer under its own terms; Anthropic does not use API data to train its models by default.
  • Notifications. When new mail matters, Aina sends a short notification to its owner's phone. For one email, that text is the sender's name and a short summary of the message, and tapping it opens a link that carries the sender's email address. For several emails, it is a digest of up to 600 characters with one such line for each. It is delivered through Google's Firebase Cloud Messaging and, for browsers, the web push service of the browser's maker (Google, Mozilla or Apple).
  • An optional tunnel. The owner's phone normally reaches Aina over a private network (Tailscale) or the local network. If its owner instead turns on a Cloudflare tunnel, the traffic between the phone and the computer passes through Cloudflare, which can see it.
  • Aina does not use Google user data to develop, improve or train general artificial intelligence or machine learning models.
  • Apart from the services above, Aina does not share Google user data with anyone.

Google API Services User Data Policy

Aina's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google account's third-party access page. Data Aina has stored can be deleted by its owner.

Contact

Questions about this policy can be raised on the project's issue page.
