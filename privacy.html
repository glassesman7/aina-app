Privacy policy

Last updated October 28, 2026

Aina is a personal assistant run privately by one person for their own use. The only Google account it connects to is its owner's. This page describes what it does with data from that account.

What Aina accesses

  • Gmail: reading messages so it can answer questions about them and tell its owner about mail that matters; changing labels; and sending mail only when its owner asks it to.
  • Google Calendar: reading the list of calendars, and reading, adding, moving and cancelling events.

Where the data goes

  • Data is processed and stored on computers its owner controls. It is not sold, rented or shared with anyone, and it is not used for advertising.
  • To answer a request, the relevant text may be sent to the Anthropic API (Claude), which processes it to produce the answer. Anthropic does not use API data to train its models by default.
  • Aina does not use Google user data to develop, improve or train general artificial intelligence or machine learning models.

Google API Services User Data Policy

Aina's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google account's third-party access page. Data Aina has stored can be deleted by its owner.

Contact

Questions about this policy can be raised on the project's issue page.
